# Dự Án Dự Báo Giá Nhà (Linear Regression)

Dự án sử dụng thuật toán Hồi quy tuyến tính (Linear Regression) để dự báo giá nhà dựa trên diện tích.

## 📁 Cấu trúc dự án
- `data.csv`: Dữ liệu diện tích (m2) và giá nhà (triệu VNĐ).
- `main.py`: Code Python đọc dữ liệu, huấn luyện mô hình và dự báo.
- `README.md`: Hướng dẫn chi tiết dự án.

## 🚀 Cách cài đặt và chạy

1. Cài đặt thư viện:
```bash
pip install pandas scikit-learn
```

2. Chạy file code:
```bash
python main.py
```
